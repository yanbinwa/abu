# DLBu 模块开发说明

DLBu 是深度学习数据准备辅助模块，主要为历史 Caffe 工作流标准化图片并生成训练集和验证集清单。它不包含完整的模型训练、服务或交易预测流水线。

## 文件索引

| 文件或目录 | 作用 |
| --- | --- |
| `ABuDLImgStd.py` | 查找图片、修正扩展名并转换为 JPEG |
| `ABuDLTVSplit.py` | 切分训练集和验证集 |
| `pb` | Caffe deploy、solver 和 train val 配置样例 |
| `sh` | LMDB、均值文件和训练脚本样例 |

## 主要入口

`std_img_from_root_dir` 批量标准化图片，`train_val_split` 按标签目录生成训练验证数据。图像处理依赖 Pillow，Caffe、LMDB 和相关 shell 环境需另行准备。

## 数据要求

输入图片目录结构需要稳定表达类别。执行格式转换前应备份原始数据，并记录坏图、重复图和转换失败。训练验证划分应固定随机种子，避免同源或连续样本泄漏到两个集合。

## 扩展规则

- 数据预处理和模型训练保持分离。
- 新增格式时保留颜色空间、尺寸和标签映射说明。
- 不在仓库提交大规模训练数据、模型权重或生成缓存。
- 使用现代框架重建训练流程时，可保留本模块作为数据迁移参考，不必继续绑定 Caffe。
