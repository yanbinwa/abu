# Alpha158-lite v1 开发计划

1. 冻结配置、特征、标签、滚动窗口与组合规则。
2. 实现 PIT 横截面特征引擎，并测试未来数据隔离、股票池和行业缺失处理。
3. 实现下一开盘标签、同日目标排名和清除式滚动 Ridge。
4. 建立追加式试验登记，输出全截面样本外预测和研究指标。
5. 实现 Top10/Top20 保留缓冲、ATR 风险退出和统一执行账本回放。
6. 运行真实数据研究及回测，按年度和全期分析收益来源。
7. 执行完整测试、编译检查和差异检查，形成验证报告。

每一步必须通过对应单元测试后再进入下一步。任何失败版本都保留，不根据已观察结果修改 v1 参数。
