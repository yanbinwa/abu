# Alpha158-lite v1 开发计划

1. 冻结配置、特征、标签、滚动窗口与组合规则。
2. 实现 PIT 横截面特征引擎，并测试未来数据隔离、股票池和行业缺失处理。
3. 实现与统一执行器一致的下一开盘标签：停牌、开盘涨停、跳空和滑点后越界均失败关闭。
4. 实现每日等权训练、同日目标排名和清除式滚动 Ridge。
5. 建立追加式试验登记，输出全截面样本外预测、1/5/10/20/60日因子诊断和区块置信区间。
6. 实现 Top10/Top20 保留缓冲、ATR 风险退出和统一执行账本回放，同时报告压力清算净值。
7. 因子门禁通过后才运行真实资金路径、placebo和压力测试；失败则停止，不增加LightGBM。
8. Ridge通过后，将LightGBM作为唯一首轮挑战模型；不得在同一历史区间搜索模型家族。
9. 执行完整测试、编译检查和差异检查，形成验证报告。

每一步必须通过对应单元测试后再进入下一步。任何失败版本都保留，不根据已观察结果修改 v1 参数。
