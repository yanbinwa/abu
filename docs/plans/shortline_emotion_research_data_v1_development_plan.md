## 1. 计划目标

本计划把 Spec 0.3.0 转换为可顺序实施、测试和审查的工程任务。最终交付包括：

- 不依赖涨跌停事实的 PIT 市场广度、行业强度和 VCP 趋势龙头快速路径；
- 可审计的涨跌停参考价和历史制度状态机；
- 证券级 `daily_limit_facts`；
- 分市场、分板块的规则和参考价覆盖报告；
- 物理隔离的开盘/收盘情绪特征；
- 免费外部事件源的原始快照、可获得性证据和冲突审计；
- 历史行业代理、双时态题材 taxonomy、题材强度和两类龙头相对特征；
- 分离的预期预测、实际结果和 surprise 数据集；
- 独立的 VCP 日线上下文契约、短线事件增强策略 Spec 与两套不可变实验预登记；
- 通过统一风险、执行器和 placebo v2 的消融实验入口。

本计划不承诺新因子盈利。M0—M7 和 M0A 的交付目标是数据正确性和研究可复现性；M8A/M9A 与 M8B/M9B 才允许分别验证日线上下文和短线事件假设。

## 2. 工作原则

### 2.1 先修事实，再生成特征

涨跌停参考价和制度规则是连板、晋级率、炸板、涨跌停情绪和短线事件龙头的共同依赖。M1 未通过前，不生成这些正式特征。

市场上涨广度、横截面收益分布、历史行业强度和 VCP 行业内趋势龙头不依赖价格限制事实，由 M0A 使用现有 PIT 股票池和日线先行构建。M0A 不得把价格无关特征称为完整短线情绪，也不得在 M8A 预登记前查看策略收益。

### 2.2 旧结果只读保留

修正参考价和价格限制可能改变现有执行器的成交路径。必须：

- 保留现有 `pit_corrected` 输出和配置；
- 为修正后的执行语义增加新版本；
- 不在原输出目录重跑覆盖；
- 对交易差异逐笔输出原因。

### 2.3 数据层与策略层分开

M0—M7 和 M0A 不以收益优化作为完成条件。M8A 必须先冻结 VCP 上下文接入契约和实验注册表，之后才能查看日线上下文收益；M8B 必须先冻结短线事件增强契约，之后才能查看事件增强收益。

### 2.4 事实、特征、标签物理隔离

存储和加载接口必须让以下错误在结构上难以发生：

- 策略加载器读取未来收益；
- 预测训练读取预测期之后的样本；
- 当前题材 taxonomy 回填历史；
- 历史查询结果伪装成当时实时可见数据。

### 2.5 失败关闭和显式降级

未知参考价、未知价格制度、未知 ST、未知题材可用时间均不得填成有利值。降级结果必须携带原因码，低覆盖日的市场状态为 `UNKNOWN`。

### 2.6 一次只改变一个研究变量

M9A/M9B 的实验顺序固定为：市场上下文 shadow、市场风险覆盖、行业强度排序、行业内趋势龙头、涨跌停情绪、题材筛选、题材内龙头、日线超预期、精细事件增强。不得一次混合所有新因素后再倒推贡献。

首轮市场上下文不改变成交；行业强度和趋势龙头优先参与排序或同分决胜，不直接叠加多个硬过滤。任何硬过滤版本必须保持上位 Spec 要求的最低交易数和独立入场日簇。

## 3. 范围和依赖

### 3.1 复用依赖

- `SelectionPanelV2` 的 PIT 股票池和字段掩码；
- 原始/复权行情、成交额、换手率、流通市值；
- `TradeIntent`、组合风险引擎和统一执行器；
- 数据快照、placebo v2 和研究统计；
- 现有历史行业作为明确标记的 `industry_proxy`。

### 3.2 必须修复的依赖

- 原始行情未保留 `pre_close/reference_price`；
- 执行器以最后有效原始收盘价计算当日涨跌停；
- `ABuPriceLimit` 在判断板块前把全部 ST 映射为5%；
- 退市整理、重新上市和特殊交易状态不完整；
- 上海历史 ST 状态覆盖不足。

### 3.3 外部依赖

- AKShare/东方财富近期事件池；
- eltdx/通达信公开协议的事件、竞价和题材数据；
- 可选辅助校验源；
- 交易所规则和可获得的证券参考数据。

所有外部依赖都必须允许禁用；禁用后 M1—M4 核心日线链路仍应运行。

## 6A. M0A：价格无关市场与行业快速路径

### 6A.1 任务

#### M0A-T1 冻结权威市场广度分母

先落盘 `market_industry_context_v1.json`，冻结信号价格空间、沪深300基准、5/20/60日收益窗口、MA20/60/120、20日新高窗口、成交额5日/前20日非重叠窗口、最低行业成员数、最低覆盖率和并列排名方法。

基于 `SelectionPanelV2` 定义逐日分母：

- 当日已上市且未退市；
- 达到对应指标最短历史长度；
- 当日收盘价和所需移动均线可用；
- 停牌、ST 未知、行情缺失分别计数；
- 不因缺失字段删除证券后重新解释为全市场。

同时生成 `full_eligible` 和 `signal_eligible` 两个不可混用的范围，并分别统计已知 ST、ST 未知和停牌数量。趋势、新高/新低和收益使用冻结快照的复权信号价格。

构建 `market_breadth_asof_close`，至少输出上涨比例、横截面收益中位数、MA20/60/120以上比例、20日新高/新低比例和等权市场收益。与现有 VCP `breadth_ma120` 逐日对账；差异必须归因到分母、历史长度或缺失政策。

#### M0A-T2 构建历史行业强度

新增 `ABuIndustryStrength.py` 和 `build_industry_strength_features.py`，基于信号日可见的历史行业矩阵生成：

- 5/20/60日行业等权收益；
- 20日相对市场收益；
- MA20/60/120以上成员比例；
- 20日新高比例、上涨成员比例和成员收益中位数；
- 成交额扩张、收益离散度、成员数和覆盖率；
- 同日跨行业的连续分量排名。

收益、成交额扩张和离散度严格使用 Spec 第12.1节公式。不得生成“主线行业”硬标签，不得把行业结果命名为题材结果。

#### M0A-T3 构建 VCP 行业内趋势龙头

新增日线趋势龙头表，保存个股在信号日行业内的：

- 20/60日相对收益；
- 残差动量、MA120斜率和距120日新高排名；
- 上涨期进攻强度和下跌期抗跌性；
- 成交额占比、流动性排名；
- 截至当日的突破顺序和同步突破数量。

冻结所有观察窗口、最小样本和并列排名规则。原始值与排名同时保存，不计算策略总分。

#### M0A-T4 覆盖与冗余诊断

输出：

- 按日、交易所和行业的字段覆盖；
- 行业成员缺失及变更原因；
- 新分量与现有残差动量、MA120斜率、收缩紧度和突破强度的同日 Spearman 相关；
- 全样本与共同覆盖样本数量。

本阶段不得读取未来收益、交易 P&L 或根据表现选择阈值。

### 6A.2 测试

- 修改未来行情或未来行业变更不改变历史特征；

### 15.1 实验顺序

M9B 短线事件增强实验：

2. 覆盖合格样本上的题材强度选择；

5. 覆盖完整样本上的精细事件增强；
6. 统一风险、placebo、压力和市场状态报告。

相邻实验只改变一个维度，共同样本实验和全覆盖实验分别报告。行业和龙头首轮只改变排序或同分决胜；硬过滤作为单独版本，不与新评分同时引入。

### 15.2 评价口径

风险覆盖层主要报告：

- 最大回撤；
- Expected Shortfall；
- 三跌停清算回撤；
- 收益保留率；
- 平均市场敞口；
- 拒单和容量损失；
- 被过滤交易自身后续表现；
- 收益改善中由降低平均市场敞口解释的比例。

选股层主要报告：

- 成本后 R 期望及交易簇置信区间；
- 同执行路径 placebo 分位数；
- 市场和行业 beta；
- 换手、容量和滑点；
- 前几笔盈利集中度；
- 跨年度和市场状态稳定性；
- 新因子与现有评分分量的同日相关性；
- 1/3/5/10/20日 MAE、MFE、假突破率和进入 `+1R` 的概率；
- 初始止损、停滞退出和跟踪止损构成；
- 全样本、共同覆盖样本及样本损失。

### 15.3 Placebo 按假设拆分

- 市场风险覆盖：固定原始交易意图，比较被接受与被过滤交易，不用随机股票替代其主要结论；
- 行业/题材方向选择：匹配日期、价格、流动性、波动率、市值和可执行条件，但不匹配正在检验的行业/题材强度；
- 行业/题材内龙头：固定行业或题材后，在可比成员中随机选择；
- 完整组合：匹配已启用的市场状态和上游方向暴露，评价剩余个股选择能力；
- 超预期：在相同期望分组内比较 surprise 分位。

每类 placebo 使用相同风险、现金、成交和退出路径，并保存独立版本号。

### 15.4 多重检验

- 同一注册表内的市场上下文、行业、龙头、题材和超预期变体全部进入其预登记检验族；
- 报告原始 p 值和 FDR q 值；
- 消融用于归因，不从中追选历史最优候选；
- 未达到上位 Spec 门槛时保持 `research_only`。

### 15.5 完成条件

- 所有实验使用同一事实快照、执行器和费用；
- placebo 按待检验假设选择匹配字段，没有提前控制掉目标因子；
- 风险改善没有被描述为选股 alpha；
- 新增硬过滤没有通过减少到不足样本而获得准入；
- 未通过门槛的策略不进入模拟盘候选。

## 18. 主要风险与处理

| 风险 | 影响 | 处理 |
|---|---|---|
| 历史参考价拿不到 | 无法可靠重建涨跌停 | 保持 UNKNOWN，缩小正式样本，不用昨日收盘伪造 |
| 上海 ST 仍不完整 | 全市场情绪偏向深市 | 分市场报告、95%门槛、状态 UNKNOWN |
| 2026制度变化遗漏 | 最新样本误标 | 规则表带有效日期，固定边界测试 |
| 免费源历史很短 | 题材/竞价样本不足 | 日线核心先行，从现在持续归档 |
| 供应商字段变更 | 静默错列 | schema hash 变化即停止规范化 |
| 回补分类事后修订 | 历史前视 | availability evidence 和字段类别门禁 |
| 特征读取未来标签 | 虚假收益 | 物理拆表、独立加载器和负向测试 |
| 题材 taxonomy 回填 | 题材历史失真 | 双时态映射和 retrospective 标记 |
| 新旧市场广度同名异义 | 实验不可比 | M0A 对账后冻结唯一权威分母和版本 |
| 行业/龙头硬过滤使样本枯竭 | 偶然收益被误当有效 | 先 shadow/排序，硬过滤单独登记并执行最低样本门槛 |
| 短线情绪与 VCP 周期错配 | 错误退出中期趋势仓位 | 分别评估1—5日假突破与20日/最终收益，不自动触发退出 |
| Placebo 过度匹配目标因子 | 把行业或题材效应控制掉 | 按方向选择、组内龙头和完整组合拆分 placebo |
| 修复执行器改变旧结果 | 无法归因 | 保留旧模式、新版本和逐笔差异报告 |
| 研究自由度过大 | 过拟合 | 策略 Spec、预登记、共同样本和 FDR |
| 竞价后开盘成交不现实 | 执行前视 | 在分钟执行器完成前仅事件研究 |

## 22. 整体完成定义

本计划完成必须同时满足：

1. 市场广度、行业强度和 VCP 趋势龙头可以不依赖价格限制与外部源确定性重建；
2. 新旧市场广度已对账并冻结唯一权威口径；
3. 涨跌停参考价不再无条件使用昨日实际收盘；
4. 板块、ST、日期和特殊交易状态规则通过固定样例；
5. 证券级涨跌停事实可追溯且 UNKNOWN 不被误标；
6. 上海 ST 和规则覆盖不足不会伪装成全市场情绪；
7. open/close 特征、未来结果和模型预测物理隔离；
8. 外部历史数据具有字段级可获得性证据；
9. 题材 taxonomy 为双时态且不回填历史；
10. 免费源中断不影响 M0A 和核心日线事实链路；
11. 策略回测前已冻结 VCP 接入契约、策略 Spec 和实验注册表；
12. 市场风险覆盖、行业选择和组内龙头独立消融；
13. 各类正式实验使用与待检验假设匹配的 placebo；
14. 硬过滤没有通过样本枯竭绕过最低统计门槛；
15. 所有正式实验通过统一风险、执行器和统计门禁；
16. 旧数据、旧执行模式和旧结果未被覆盖。

在以上条件完成前，项目状态保持 `research_data_under_construction`，不得进入实盘评估。
