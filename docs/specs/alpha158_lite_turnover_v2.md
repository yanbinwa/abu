# Alpha158-lite 换手约束组合 v2

v2 只检验一个机制变化：使用严格可成交标签、每日等权训练的 `alpha158_lite_v1` 样本外分数，排名原因每天最多替换 1 个持仓。输入研究报告的配置哈希必须与冻结 v1 配置一致，否则失败关闭。

- 目标持仓：10；
- 候选深度：每日前 50；
- 每日排名替换上限：1；
- 比较当前最差持仓与最高排名的非持仓候选，只有候选排名更高才替换；
- 初始建仓和事件退出造成的空位可以补齐；
- 初始止损、跟踪止损和停滞退出即时执行，不占排名替换额度；
- 模型、特征、样本外预测、股数、风险、成交、费用和滑点全部保持不变；
- 不增加固定持有期限，不搜索替换数量或候选深度。

本版本是在观察到 v1 高换手之后提出，属于诊断性历史实验。即使结果改善，也不能视为独立样本外证据。
