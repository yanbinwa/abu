## 冻结实验

1. baseline：v3低换手规则，动态止损同步保持关闭，作为原版对照。
2. no_rank_exit：仅取消自愿排名卖出；止损、追踪和停滞退出照常。
3. cost_gate：自愿换仓必须通过历史收益校准和成本门槛。
4. diversified_20：仅将最大持股数由10增加到20，风险预算不变。

四组分别按单边25/40/60bp运行，不在结果揭示后挑参数。增加持股上限不保证
能增加实际持仓或降低风险；同时报告暴露、波动、压力净值及同风险参考。

## 时点与校准

沿用已经生成的样本外预测。每个信号日先对全候选评分取横截面百分位，分箱边界
固定为0/50/80/90/95/98/99/99.5/100百分位。使用20日价格超额收益标签。
标签从t+1开盘到t+20收盘；只有标签结束日严格早于决策日才可进入校准。
每个历史信号日在每个箱中先求均值，再对日期等权。最近最多252个成熟日期，
候选与持仓共同有效日期至少126个。持仓掉出前100时使用全候选预测，不虚构分数。

同一天两箱收益之差估计预期替换优势，以19阶Newey-West标准误处理重叠标签；
保守优势=均值−1.645×标准误。该近似置信界仅是门槛，不是策略显著性结论。
不根据观察结果强制单调、不反转分数，不减去未经校准的原始Rank分数。

四组从首次满足126个成熟日期的同一天重新以100万元现金启动，公平隔离校准
预热期。另重放原始完整基线，对保存的逐日净值和成交做黄金对照。

## 成本与订单

替换优势须大于卖出现持仓与买入候选两条腿的佣金、最低5元佣金、过户费、
卖出印花税、当次情景双边滑点以及额外5bp缓冲。买入佣金按最小100股估计，
避免风险审批缩量后低估最低佣金。价格只用决策日收盘价；它是保守估计，
不能保证覆盖跳空和公司行为导致的全部实际误差。

只过滤排名替换，不以“超额收益大于成本”冒充相对现金的绝对收益预测。
当排名卖出获批，该轮只允许通过该持仓成本比较的候选买入；若未获批，
原有空闲槽位买入规则保留。即便通过成本门槛，次日仍可能因统一风险/成交
拒绝而保留现金。卖出和买入不是原子交换，实际拒单必须保留在账本。
事件退出永远不受此门槛阻拦。
