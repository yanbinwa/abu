# Alpha158-lite 低频组合 v3

本版本将交易频率设为显式约束，并使排名决策更接近20日预测周期：

- 每5个交易日评估一次排名；
- 候选连续两次评估进入前50才允许买入；
- 排名卖出前至少持有10个交易日；
- 连续两次评估跌出前100才允许排名退出；
- 每次评估最多因排名替换1只；
- 初始止损、跟踪止损和停滞退出仍逐日执行；
- 事件退出形成的空位只在下一排名评估后补充；
- 不设置固定持有20日或强制到期卖出；
- 模型和样本外分数完全复用 `alpha158_lite_v1`。

目标交易频率为每年不超过120次买入。该目标是产品约束，不作为收益优化参数。

本版本是在观察 v1/v2 后提出，历史结果属于诊断证据，不能视为新的独立样本外验证。
