# Alpha158 前瞻双影子账户协议 v1

本实验验证一个已经由历史数据提出的假设：取消持续排名下降卖出，能否在不恶化回撤的情况下提高净收益。2026-09-30 及以前的历史已经参与研究，不再作为新的验证集。历史表现不能解释为该实验的预期收益。

## 注册和对照

- 每个账户初始现金 100 万，空仓启动，不继承历史订单或已有模拟盘。
- `baseline`：现有 v3 低换手规则，保留排名退出和事件退出。
- `event_exit_only`：仅取消排名退出，止损、移动止损、停滞退出仍保留。
- 两个账户使用相同股票池、特征、模型、信号日期、风险限制、费用、滑点和成交规则。模型使用注册前已严格成熟的 20 日标签拟合一次，随后冻结。此模型更新方式与原滚动历史回测不同，不能把两者收益直接拼接。
- 当前实现不启用加仓、分批止盈、参数搜索或收益驱动的模型更新。
- 注册时复制代码、配置、依赖版本和市场数据到独立目录。之后命令自动进入冻结代码运行；依赖版本变化则拒绝继续。

## 时间与成交

每个交易日北京时间 15:15 后采集当日收盘数据。收盘决定次交易日订单并冻结数量；次日运行先处理已冻结订单，再计算新的信号。初次运行只产生收盘信号，不补做历史成交。

只允许新增一个真实交易日。周末、未收盘或没有当日行情时等待；跨交易日漏采、历史矩阵修订、股票池变化、资料冲突均拒绝提交，不允许事后补齐并冒充前瞻记录。公休日以实际指数交易数据为准。收到行情接口响应不等于证明行情一定完整或可成交；本项目的撮合仍为日线模拟。

深圳股票的当日 ST/退市风险名称取自当日市场快照；缺失名称的股票不能据此开新仓。保持原研究股票池，不因上海当日名称可得而临时扩大模型适用范围。股票池及其他静态资料冻结，因此退市、重组等特殊事件仍需要额外核查。

现金分红的未来支付日保留为日历日期，在除权日确认应收权益、支付日到账；统一按 20% 的保守税款预留假设计入净额，不模拟持有期退补税。当前送转股权益跨卖出后的独立记账尚未验证：持仓遇到送转股、缺失支付日、冲突分红记录时停止，不编造收益或跳过日期。修复必须保留原失败记录并重新审查协议；不能挑选收益较好的重启时点。

## 归档与重放

默认目录：`/Users/wjy/abu/shadow/alpha158_forward_v1`。

- `genesis/`：注册协议、模型及训练范围、数据哈希、初始面板、空账户状态。
- `runtime/`：冻结代码及配置，不含账户密钥。
- `data/`、`collector/`：专属可追加数据缓存，与既有 VCP 模拟盘隔离。
- `sessions/YYYYMMDD/`：原始行情响应、标准化快照、分红资料、增量面板、完整特征和预测、双账户 NAV/订单/成交/事件/风险决定及状态检查点。
- 每日目录通过哈希链接，两个账户一次性原子提交。提交前失败不会改变已确认账本；同日再次运行返回已提交状态。
- `summary.json` 仅是展示副本，权威状态从最后一个已校验提交恢复。
- `audit` 校验提交链，重算特征和预测，并重放成交与 NAV。空实验审计通过只说明注册完整，不能说明前瞻策略有效。

哈希用于发现意外修改和复现，不是第三方公证或防管理员篡改的签名。检查点仅供本地内部使用，不能加载陌生来源的 pickle 文件。

## 预先约定的评估

从第一个真正前瞻交易日起，在第 6、9、12、18 个月的首个已记录交易日检查样本数量。两个账户均至少有 30 个买入成交日期簇才进入一次正式评估；不足则按固定计划延期，到 18 个月仍不足则标记证据不足。相同日期的多只股票只计一个簇；日期簇仍可能相关，不能称为 30 个独立样本。

延期仅由样本数量决定，不能根据收益决定早停、延长或重新选参。正式评估一旦到期，日更停止等待人工审查，不反复检验直到通过。

一次性报告所有预注册情景：

1. 主情景单边滑点 25bp，同时重放 40bp 和 60bp 压力情景。
2. 每个情景中候选净收益须大于零且高于对照；候选最大回撤不劣于对照，且不超过 15%。
3. 候选三次连续跌停估值压力的最大回撤不超过 15%，终值收益须大于零。
4. 主情景按共同交易日配对、20 日块、5000 次、固定随机种子计算收益差的 95% 区间，区间下界须大于零。

这些门槛是研究筛选规则，并不保证未来回撤低于 15%，也不是严格独立样本显著性证明。全部通过仍仅为人工复核候选，`paper_admitted=false`、`live_admitted=false`；不会切换现有模拟盘或发送订单。

## 运行

在项目根目录使用虚拟环境：

```sh
.venv/bin/python scripts/run_alpha158_forward_shadow_v1.py init
.venv/bin/python scripts/run_alpha158_forward_shadow_v1.py status
.venv/bin/python scripts/run_alpha158_forward_shadow_v1.py run
.venv/bin/python scripts/run_alpha158_forward_shadow_v1.py audit
.venv/bin/python scripts/run_alpha158_forward_shadow_v1.py evaluate
```

`init` 仅一次，目录存在则拒绝覆盖。`run` 应在每个真实交易日 15:15 后执行。`evaluate` 提前调用只返回未到期。`--root` 可以指定另一目录，但不得通过平行创建相同候选来挑选有利结果。

本次交付包含可运行日更入口，不自动安装后台任务、开机服务或通知。若没有每日执行，实验会缺失交易日并停止，因此注册完成不等于已经开启持续采集。已有模拟盘及其通知任务不受此入口调度。
