# 动态止损与组合风险同步 v1

## 目标

在不修改选股信号、单笔风险比例、组合风险上限、行业上限、压力上限、费用和滑点的前提下，让组合风险引擎使用上一交易日收盘后已经形成、且下一交易日可以执行的当前止损价。

## 冻结边界

- 单笔初始风险仍为净值的 `0.25%`；
- 组合开放风险仍为净值的 `2%`；
- 行业开放风险仍为净值的 `0.6%`；
- 同日新增风险仍为净值的 `0.75%`；
- 单股上限仍为 `8%`，总股票仓位上限仍为 `80%`；
- 压力损失上限仍为净值的 `6%`；
- VCP、残差动量、Alpha158评分、排名确认和所有退出公式保持不变；
- 动态止损在信号日收盘后写入风险状态，只影响下一交易日及以后订单，不读取未来开盘价；
- `initial_r_cash_frozen` 保持冻结，绩效R倍数不随移动止损改变。

## 状态定义

持仓同时保存：

- `initial_stop_raw`：成交时冻结，用于初始R和历史绩效；
- `current_stop_raw`：最近一个收盘后已经确定的可执行止损，用于下一交易日组合开放风险。

组合开放风险定义为：

```text
open_risk = max(0, current_mark_raw - current_stop_raw) × quantity
```

当前止损缺失时回退到初始止损。送转发生时，两个原始价格空间止损均按公司行为因子调整。

## 时序

```text
当日开盘：使用上一日已发布的 current_stop_raw 审批新订单
→ 当日成交与记账
→ 当日收盘：退出引擎更新 adjusted current stop
→ 映射到当日 raw price space
→ 保存为下一交易日风险审批状态
```

## 拒单原因

非压力约束先独立计算 `pre_stress`。只有压力约束把正的 `pre_stress` 进一步缩小时，才记录 `STRESS_LOSS`。若开放风险等上游约束已经把数量降为零，不再连带标记压力损失。

## 实验要求

动态同步必须通过显式开关运行，旧冻结回测默认关闭。验证同时运行：

1. 当前代码关闭同步，必须逐项复现旧经济结果；
2. 当前代码开启同步，使用相同VCP意图或相同Alpha158 OOS预测；
3. 比较收益、最大回撤、平均仓位、交易次数、费用、拒单、年度表现和三个跌停清算结果；
4. 不因仓位仍低而提高风险比例或根据结果搜索新阈值。
