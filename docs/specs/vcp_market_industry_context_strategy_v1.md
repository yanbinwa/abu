# VCP 市场与行业上下文策略 v1

| 字段 | 内容 |
|---|---|
| 状态 | Frozen for historical diagnostic |
| 冻结日期 | 2026-10-03 |
| 基础策略 | `vcp_residual_v2` |
| 退出策略 | `stop_trailing_stagnation_v2` |
| 上下文配置 | `vcp_context_overlay_v1` |
| 实验注册表 | `vcp_context_experiment_registry_v1` |

## 1. 决策与执行

- 个股、市场和行业特征都只使用信号日收盘后 `15:05 Asia/Shanghai` 可见的数据。
- 买入意图继续在下一个交易日开盘通过统一风险引擎和执行器。
- 买入价格上限、最大跳空、初始止损、1R 定义、订单有效期、T+1、停牌、连续跌停和退出优先级全部沿用基础策略与 `risk_v1`。
- 市场上下文只审批新风险。卖单和已有持仓的事件退出不被 NORMAL/CAUTION/RETREAT/UNKNOWN 阻止。

## 2. 市场状态

使用 `market_breadth_asof_close.signal_eligible`。覆盖率低于 98% 或任一必要字段缺失时为 UNKNOWN。

RETREAT 满足任一条件：

- MA120 以上比例小于等于 35%；
- MA60 以上比例小于等于 40%；
- 等权市场 5 日收益小于等于 -5%；
- 20 日新低比例大于等于 20%。

NORMAL 必须同时满足：

- MA120 以上比例大于等于 55%；
- MA60 以上比例大于等于 55%；
- 等权市场 5 日收益大于等于 0；
- 20 日新低比例小于等于 8%。

其余完整覆盖日为 CAUTION。新风险倍率依次为 NORMAL 1.0、CAUTION 0.5、RETREAT 0、UNKNOWN 0。首轮只运行 shadow，不改变真实订单或成交。

## 3. 行业与趋势龙头

- 行业方向只使用 `excess_return_20d_vs_market_rank`，覆盖率至少 80%。首轮只改变 shadow 排序。
- 行业内趋势龙头只使用 `residual_momentum_rank_within_industry`，覆盖率至少 80%。它只在固定行业顺序内改变成员次序。
- 两层不合成总分，不增加硬过滤，不搜索历史权重。
- 原始 VCP 分数、行业原始值和行业内原始值全部保留，以便做冗余和相关性诊断。

## 4. 实验边界

市场风险覆盖、行业方向选择和行业内龙头是三个独立实验。市场覆盖主要评价尾部风险和收益保留，不能解释为选股 alpha；行业与龙头分别使用方向 placebo 和固定行业内 placebo。

2021-01-14 至 2026-09-30 只作为已观察历史诊断期。真正前瞻从 2026-10-09 或之后第一个成功归档交易日开始，至少持续 6 个月且达到 30 个独立入场日簇。前瞻期不得根据结果修改本配置。

## 5. 失败关闭

- 缺市场状态时不新增风险；
- 缺行业数据时保持基础排序并记录原因；
- 缺行业内龙头数据时保持该行业的基础成员次序；
- 所有降级均保存原因码；
- 没有实验注册表时，正式上下文回测拒绝启动。
