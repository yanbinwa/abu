# Alpha158 事件退出一致标签 v1

## 1. 目的与边界

本规格定义一个独立研究标签 `alpha158_event_exit_r60_v1`，用于检验“与实际事件退出路径一致的目标”能否提高七族模型的样本外账户表现。

它不修改 `alpha158_ml_factor_optimization_v1`，不回写既有20日标签，不改变正式选股、风险、退出或模拟盘账户。历史实验只用于筛选，任何通过结果仍需进入前瞻 shadow。

## 2. 入场合同

- 信号仅使用信号日收盘后可见数据；
- 计划成交为下一交易日原始开盘价，加单边25bp滑点；
- 复用现有涨跌停、停牌、股票池和最大买价检查；
- 实际成交价不高于初始止损时，以 `STOP_INVALIDATED`失败关闭；
- 初始止损为信号日收盘减2倍ATR，并保留信号日原始/复权映射；
- 入场失败的样本保留键和失败原因，但目标值为空，不能作为训练标签。

## 3. 退出合同

按当前Alpha158事件退出优先级逐日推进：

1. 收盘确认初始止损；
2. 达到1R后启用最高收盘价减3倍ATR的跟踪止损；
3. 持有满20日且MFE不足0.5R时停滞退出；
4. 退出信号后，在下一可执行原始开盘成交并扣单边25bp滑点；
5. 跌停、停牌或滑点越过跌停价时顺延；
6. 60个持有交易日仍无退出信号时按收盘价形成 `TIME_MARK_60`研究标记。

目标是每股价格变化除以入场冻结1R。v1不包含依赖实际下单数量的最低佣金，因此它是 `gross_price_r`，不是账户净利润标签。正式验收仍以完整账户回放为准。

## 4. PIT与成熟边界

无论交易提前退出与否，训练可用时间统一冻结为信号日后第61个交易日。禁止因某些交易提前止损而提前进入训练集，避免结果依赖型成熟造成选择偏差。

训练、验证和早停使用的最后标签成熟日都必须早于预测时点。交易预测保留当时完整候选池，不能按未来标签是否为空过滤。

## 5. 公司行为与价格尺度

止损和初始风险保留原始、复权两个尺度。退出成交价按退出日原始开盘成交，再用该日原始/复权开盘比例映射到连续价格尺度。原始公司行为事实仍由账户执行器负责；标签只表达每股价格R，不取代账户账务。

## 6. 验证顺序

1. 用合成路径验证止损失效、止损、跟踪、停滞、跌停延期和固定成熟日；
2. 与真实账户已平仓交易对账退出原因、退出日期和R，分别报告一致率及差异原因；
3. 生成全候选池标签和覆盖报告；
4. 冻结相同因子、折、模型和执行规则，只替换目标；
5. 与20日标签版本进行配对账户比较；
6. 主要门槛仍为成本后账户增量、回撤、ES及区块Bootstrap，不以标签IC单独准入。

## 7. 失败关闭

出现下列任一情况时不得训练：标签键重复、固定成熟边界越界、执行失败却存在目标值、可执行成交的初始R非正、来源配置哈希不一致，或真实账户对账存在未解释的系统性差异。
