# VCP 模拟盘运行规范 v1

## 1. 目标

从 2026-10-03 起，使用冻结的 `vcp_residual_v2 + stop_trailing_stagnation_v2` 运行 100 万元研究模拟账户，并在 2026-11-03 完成首月评估。模拟盘不发送真实证券订单。

## 2. 时间顺序

每个交易日收盘后执行一次：

1. 获取当日全市场收盘快照并保存原始快照和 SHA256；
2. 使用当日开盘价处理上一交易日已经冻结的订单；
3. 计入佣金、过户费、印花税和 25bp 双边滑点；
4. 使用当日收盘数据更新净值和退出状态；
5. 生成当日信号并完成风险审批；
6. 冻结数量、最高买入价、初始止损和风险金额，等待下一交易日执行；
7. 原子保存账户状态并重新导出账本和日报。
8. 若产生实际买入或卖出成交，将成交提醒加入企业微信智能机器人发送队列。

这一顺序保证开盘成交数量在看到开盘价前已经确定。

## 3. 冻结参数

- 初始资金：1,000,000 元；
- 最大持仓：10 只；
- 单笔风险：净值的 0.25%；
- 组合开放风险：净值的 2%；
- 最大总仓位：80%；
- 成交模型：下一交易日开盘，双边 25bp 滑点；
- 退出：初始止损、达到 1R 后的 3ATR 移动止损、20 日停滞退出；
- 股票池、交易状态和费用均沿用 selection engine v2。

配置和关键实现文件的 SHA256 在初始化时写入 `state.json`。后续代码或参数发生变化时，模拟盘拒绝继续运行，必须另建版本。

## 4. 行情更新

日行情以 AKShare 的全市场收盘快照为主：

- 未复权 OHLC 用于实际成交和账户估值；
- 根据行情参考昨收递推连续前复权序列，用于策略信号；
- 成交量从手换算为股；
- 成交额、换手率和流通股本写入研究原始行情；
- 持仓和待买股票的公司行为在运行前单独刷新；
- 指数数据最后提交，使中断后的任务可以安全重跑。

若发现缺失超过一个交易日、市场快照少于 3,000 只有效股票、持仓公司行为无法获取或配置哈希变化，任务失败关闭，不生成交易。

## 5. 持久化文件

目录：`/Users/wjy/abu/paper/vcp_residual_v2/`

- `state.json`：唯一可恢复账户状态；
- `summary.json`：机器可读汇总；
- `REPORT.md`：用户日报；
- `daily_nav.csv`：每日资金、仓位和压力净值；
- `fills.csv`：成交及拒单；
- `orders.csv`：冻结订单；
- `reservations.csv`：现金和风险预留；
- `intents.jsonl`：全部交易意图；
- `risk_decisions.jsonl`：组合风险审批；
- `exit_reasons.csv`：退出原因；
- `position_events.csv`：分红送转事件；
- `market_snapshots/YYYYMMDD/`：当日原始市场快照。
- `wecom_notification_state.json`：已经推送的成交订单 ID；
- `last_wecom_notification.md`：最近一条企业微信成交提醒。

所有明细由 `state.json` 中的追加历史重新导出，重复运行同一个交易日不会重复成交。

企业微信只推送 `filled` 状态的买卖成交，不推送候选信号、风险拒单、休市日或普通净值变化。消息包含股票、方向、成交价、数量、交易原因、费用、滑点、账户资产、累计收益和仓位。推送按成交订单 ID 去重，写入机器人队列后由已绑定的企业微信长连接服务负责发送和失败重试。

## 6. 首月评估

2026-11-03 后至少报告：

- 成本后累计收益和最大回撤；
- 日均和峰值仓位；
- 成交数、胜率、Profit Factor 和平均 R；
- 初始止损、移动止损和停滞退出贡献；
- 佣金、税费和滑点贡献；
- 与同期沪深 300、原回测预期和匹配 placebo 的差异；
- 未成交、停牌、涨跌停和数据失败记录。

一个月结果只用于诊断执行和信号行为，不作为直接实盘准入依据。
