# 基本面主数据源范围决策（2026-10-04）

## 结论

**暂停采购和接入基本面主数据源，但不删除基本面研究分支。**

BigQuant、RQData 或其他单一供应商都不是项目运行的强制依赖。当前价格技术、VCP、短线情绪数据、组合风险和成交执行链路允许在没有财务报表数据时继续运行。`alpha158_multifactor_cost_aware_v4` 的价值、质量和投资主题必须继续失败关闭，不得把缺失主题静默删除后仍沿用 v4 名称或结论。

## 允许继续的范围

- 冻结的残差动量、短期反转、趋势突破和 VCP 历史基线；
- `alpha158_lite_v1`、`alpha158_lite_turnover_v2` 和 `alpha158_lite_low_turnover_v3` 的价格技术基线；
- 组合风险、资金账、费用、滑点、涨跌停、停牌和 T+1 执行；
- 不依赖财务报表的市场广度、短线事件、题材、龙头和超预期前瞻数据积累；
- 现有总市值、流通市值和股本数据的独立审计与执行容量用途。

## 保持阻断的范围

- `alpha158_multifactor_cost_aware_v4` 的 B2—B5；
- E/P、CFO/P、ROA、毛利润/资产、资产增长和资本开支增长；
- 使用最新重述数值回填历史的任何基本面回测；
- 在缺少历史修订链时宣称价值、质量或投资主题已经通过 PIT 验证；
- 将流通市值代替总市值计算 E/P 或 CFO/P。

## 数据源边界

- 供应商可以替换；可审计的 PIT 财务事实不可替换为最新快照。
- 当前不创建 BigQuant API Key，不采购 BigQuant SDK，也不把试用期云端权限作为生产依赖。
- BigQuant 已验证的数据能力保留为候选证据；只有在重新启动基本面分支时才进入正式采购和接入决策。
- GitHub、AKShare 和其他免费样本只允许用于字段映射、单元测试和交叉校验，不升级为历史 PIT 主事实。

## 当前优先级

1. 保持模拟盘策略和既有失败基线冻结，不重新调参。
2. 短线情绪 M6 从 2026-10-09 或之后第一个成功归档交易日起积累连续前瞻样本。
3. 在 M1 历史参考价与 M6 连续样本门禁通过前，不启动 M7/M8B/M9B，也不让短线事件改变订单。
4. 基本面 v4 保留代码、配置、审计报告和失败原因；不继续扩大历史财报采集。

## 重新启动基本面分支的条件

满足以下任一条件后再单独立项：

- 获得覆盖退市股、公告日期和历史修订版本的结构化 PIT 数据授权；
- RQData 或 BigQuant 完成权限、价格、批量导出和本地自动化验收；
- 从当前日期开始积累的不可变前瞻财务版本达到预登记的最短历史要求。

重新启动时仍需通过公告日边界、修订前后值、TTM、单位、总市值勾稽和主题覆盖门禁，不能沿用本次供应商试点结果直接进入收益回测。
