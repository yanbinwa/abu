# VCP 2020—2024 基线诊断实验

## 1. 结论

本轮在不修改策略规则的前提下，完成了三项优先诊断：沪深300
MA200 择时基线、1,000 路径匹配型随机组合，以及组合风险审批候选的
前瞻表现比较。

当前 `vcp_residual_v2 + stop_trailing_stagnation_v2` 在可评价的
2021-01-04 至 2024-12-31 区间取得 `+7.3777%` 成本后收益，位于匹配型
随机组合的 `83.4%` 分位。它明显高于随机中位数，但没有进入预先要求的
前 `10%`，因此仍为 `research_only / NOT_ELIGIBLE`。

结果也否定了“收益只是来自沪深300 MA200 择时”的简单解释：相同区间的
MA200 指数择时在不计费用时收益为 `-17.7149%`，按每侧 25bp 滑点执行时
收益为 `-26.4700%`。

## 2. 实验边界

- 2020 年数据只用于 252 个交易日的信号预热；正式评价从 2021 年开始。
- 策略、风险配置、成交费用和退出规则保持冻结。
- 股票策略每侧计 25bp 滑点及既有交易费用。
- MA200 基线使用前一交易日收盘和 MA200 决定下一交易日开盘持有状态；
  指数本身不可直接交易，因此仅计执行滑点，不把它伪装成可交易 ETF。
- 所有结果来自已经反复观察的历史样本，不是新的留出样本。

## 3. 沪深300 MA200 择时基线

| 指标 | 不计滑点 | 每侧25bp滑点 |
|---|---:|---:|
| 累计收益 | -17.7149% | -26.4700% |
| 最大回撤 | -32.0919% | -39.0135% |
| 平均暴露 | 30.3406% | 30.3406% |
| 买入/退出次数 | 23 / 22 | 23 / 22 |

同期沪深300买入持有收益为 `-24.5163%`。日频穿越 MA200 产生明显反复交易，
25bp 单边滑点累计约 `92,225` 元。即使完全忽略该执行成本，简单 MA200
择时仍显著低于 VCP 策略，因此 VCP 的历史收益不能只归因于这一条市场过滤。

## 4. 匹配型随机组合

1,000 条路径均使用：

- 与原策略相同的 756 个信号时点；
- 信号日可见的行业、价格、流动性、市值、波动率和 Beta 匹配；
- 相同组合风险审批、现金约束和最大持仓数；
- 相同初始止损、跟踪止损和停滞退出；
- 相同成交模型和每侧 25bp 滑点。

| 指标 | 结果 |
|---|---:|
| 实际策略收益 | +7.3777% |
| 随机组合平均收益 | +2.9848% |
| 随机组合中位收益 | +1.5280% |
| 5%分位 | -3.9183% |
| 95%分位 | +17.7582% |
| 实际策略分位 | 83.4% |
| 随机组合最大回撤中位数 | -5.3836% |

策略优于约 834 条随机路径，但仍有约 166 条随机路径收益不低于实际策略。
因此现有排序可能包含一些信息，但证据不足以通过前 10% 的选股能力门禁。

## 5. 获批与拒绝候选

风险引擎共审查 230 个候选：74 个获批或缩量批准，156 个拒绝。

不控制信号日期时：

| 分组 | 20日平均收益 | 20日中位收益 | 20日触及+1R | 20日触及初始止损 |
|---|---:|---:|---:|---:|
| 获批/缩量批准 | +2.6441% | +0.4717% | 66.22% | 54.05% |
| 拒绝 | -1.2729% | -0.6205% | 58.33% | 64.10% |

该表不能直接证明风险引擎具有选股能力，因为两个分组集中在不同日期和市场环境。
严格限定为同一信号日同时存在获批与拒绝候选后，只剩 2 个日期簇，低于冻结的
最低 20 个配对簇要求。因此审批比较结论为
`INSUFFICIENT_PAIRED_CLUSTERS`，不能据此放宽或收紧风险预算。

拒绝主要来自 `PORTFOLIO_OPEN_RISK`：153 个候选、53 个信号日，20日平均收益
为 `-1.3288%`。该结果支持暂时保持现有 2% 组合开放风险上限，但它仍是观察性
证据，不是随机对照实验。

## 6. 决策

1. 保持策略和风险参数冻结，不提高组合开放风险、行业风险或单笔风险。
2. 不把 MA200 过滤视为已验证的独立收益来源。
3. 当前策略保持 `research_only / NOT_ELIGIBLE`。
4. 下一轮只做诊断：检查残差动量、均线斜率、收缩紧度和突破强度的同日排序
   单调性，并分析初始止损交易的共同特征；不据此直接改参数。
5. 真正的准入仍需要新的前瞻样本或预注册后的独立时间样本。
