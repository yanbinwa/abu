# Alpha158 执行成本与小额订单归因

结论：当前冻结成交路径的主要成本来自滑点，不应增加最小下单金额过滤。

- 236 笔买入、228 笔卖出合计摩擦成本 23,950.52 元，占初始资金 2.395%。
- 滑点占总摩擦 80.60%，佣金占 11.18%，印花税占 7.90%，过户费占 0.32%。
- 274 笔成交触发 5 元最低佣金，但相对纯比例佣金多付的金额只有 746.53 元，占初始资金 0.075%。
- 以最低佣金除以万分之 2.5 得到的固定机械分界 2 万元做描述性分组后，小额交易并未呈现更差的已实现收益。该结果不用于挑选阈值。

删除小额订单会改变持仓、风险额度、退出和后续买入机会，不能把分组盈亏当成删除订单后的因果收益。此前等风险分配虽减少小单，却未通过跨年度稳定性门槛，因此正式策略和执行方式保持不变。
