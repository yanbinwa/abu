# 免费数据源补充 BaoStock 缺口分析（2026-10-06）

## 结论

有免费接口可以补充 BaoStock，但没有一个免费聚合接口能一次性解除当前基本面 PIT 门禁。最有价值的组合是：

1. BaoStock 继续承担价格、交易状态、历史 ST、退市证券和日频估值。
2. AKShare 的新浪/东方财富结构化财报用于补齐财务事实、公告日和更新日。
3. 巨潮官方股本变动接口用于总股本和流通 A 股事件。
4. 巨潮公告目录及原始公告文档用于重建更正前后版本；这是历史修订链唯一值得继续投入的免费路线。
5. efinance、mootdx 用作当前截面或交叉核验，不授予 PIT 主数据源地位。

qteasy、QUANTAXIS 和 StockDataMaster 主要解决下载、存储和多源回退，并不会自动产生上游不存在的历史版本信息，当前不建议为了数据缺口引入新的数据平台。

## 当前缺口重新核对

现有全市场审计包含 5448 只证券：

- 历史 ST：BaoStock 已覆盖 7,781,161 个本地价格证券日，精确覆盖率 100%，上海和深圳均通过门禁。该缺口已经解决。
- 总市值：可交易证券日覆盖率 99.962%，已经超过 99.5%门槛。
- 流通市值：覆盖率 98.426%，低于 99.5%门槛，并存在来源冲突。
- 巨潮股本事件：5223/5448 只证券有事件，覆盖率 95.87%；225 只返回显式空结果。
- 结构化财务试点：50 只样本的利润表、资产负债表、现金流量表覆盖率均为100%，9个必需字段均存在。
- 历史财务修订链：未通过。结构化接口只保留当前可见版本，不能重放更正前值。
- 经济主题：历史成分覆盖仍为0；公开概念板块接口多数只给当前成分或板块行情，不提供成员加入/退出历史。

## 接口判断

### AKShare：最值得继续使用，但按字段分工

已经实测本机 AKShare 1.18.21：

- `stock_financial_report_sina` 可用，返回长期三表、报告日、公告日期、更新日期、审计状态和币种。
- 对 `sh600068`、`sh600291`、`sh600837` 三只修订风险样本，利润表分别返回106、97、72个报告期，但同一“报告日＋类型”最大记录数均为1。因此能定位当前版本何时可用，不能恢复修订前数值。
- `stock_zh_valuation_baidu` 可用，可返回近一年日频 PE 等估值，适合和 BaoStock 做交叉核验；同样没有历史版本语义。
- `stock_info_change_name` 对上海样本只返回名称序列，没有起止日期，不能单独重建历史 ST 区间。
- `stock_share_change_cninfo` 当前因 AKShare 与项目 pandas 版本不兼容而抛出 `future.no_silent_downcasting` 配置错误；项目已有直连巨潮适配器，不需要为此升级 pandas。

判断：AKShare 可解决“规范化财务事实缺失”的大部分工作，并可提供公告/更新时间；不能解决“历史修订前版本缺失”。

### 巨潮官方股本接口：继续作为股本事件主源

项目直连 `p_stock2215` 已实测可用。单条记录包含 `DECLAREDATE`、`VARYDATE`、总股本和流通 A 股等字段，适合按照公告日和生效日重放股本状态。

目前全市场已有209,664条事件，但225只证券返回空结果。免费补齐顺序应为：

1. 巨潮公告文档中的股本变动、发行、回购和送转记录；
2. BaoStock 季频 `totalShare`、`liqaShare`；
3. 本地价格文件中的成交量/换手率反推流通股本，仅作一致性回退；
4. efinance 当前总市值/流通市值从今天起每日留档，不能回填历史。

### efinance：适合前瞻快照，不适合历史修订

官方文档显示 `get_base_info` 和实时行情包含总市值、流通市值、PE、PB、ROE、净利润等当前字段；部分财务接口包含公告日期。其主要上游是东方财富，与项目已有 AKShare/东方财富结构化数据并非独立来源。

判断：可以从2026-10-06起做不可修改的日快照，补充未来流通市值与当前基本面；无法证明历史值当时可见，也不能补历史修订链。

### mootdx：可做财务数值交叉核验

mootdx 能下载和解析通达信 `gpcwYYYYMMDD.zip` 财务文件，也能读取本地/线上行情。季度文件可用于检查财务数值和早期报表覆盖，但缺少可靠的公告可用时间和原始/更正版本关系。

判断：适合检查 AKShare/Sina 数值异常及补部分早期季度字段，不应直接用于 PIT 回测。

### qteasy、QUANTAXIS、StockDataMaster

这些项目的主要价值是本地存储、调度、统一接口和失败回退。qteasy 常用上游仍是 Tushare；StockDataMaster 封装的多个来源中，BaoStock、mootdx、Tushare、xtquant 才是真正数据源。

判断：当前项目已经具有不可修改原始响应、哈希、账本和回放能力。引入整个平台会增加迁移成本，不能补齐历史版本字段，暂不采用。

### 概念板块与经济主题

AKShare/东方财富可以返回当前概念板块成分和板块历史行情，但板块行情历史不等于历史成分。把今天的概念成员回填到过去会产生明显未来函数。

免费可行方案只有两类：

- 从2026-10-06起每日保存概念成员快照，供未来前瞻验证；
- 历史模型暂时不使用主题因子，保留行业历史分类与行业相对强弱。

## 推荐接入顺序

### P0：无需新增依赖

- 保留 BaoStock 的全市场 ST 面板和日频估值。
- 将已有 AKShare/Sina 三表扩展为全市场规范化财务事实，严格使用 `max(公告日期, 更新日期)` 后的下一交易日生效。
- 保留 `LATEST_RESTATED_VALUE_RISK` 标记，历史回测只作为研究证据。

### P1：补流通股本

- 对225只巨潮空结果证券建立冻结清单。
- 依次使用官方公告、BaoStock `liqaShare` 和成交量/换手率反推值核对。
- 三个来源冲突时保持缺失，不为了达到99.5%门槛强行选值。

### P2：修订链

- 扩展巨潮公告目录，抓取首次定期报告、更正公告和更正后报告。
- 以公告发布时间为版本可用时间，保存文档哈希、被替代版本和字段差异。
- 只有这一层通过后，历史基本面信号才可获得正式 PIT 身份。

### P3：前瞻积累

- 每日保存 BaoStock、AKShare/Sina和efinance关键截面的原始响应及哈希。
- 每日保存东方财富概念板块成员快照。
- 前瞻数据只追加，不用后来下载结果覆盖旧快照。

## 最终取舍

| 数据缺口 | 免费首选 | 能否解决 | 角色 |
|---|---|---:|---|
| 历史 ST | BaoStock `isST` | 已解决 | 主源/排除字段 |
| 日频 PE/PB/PS/PCF | BaoStock；百度估值交叉检查 | 可用，但无修订链 | 研究/前瞻 |
| 结构化三表和公告日 | AKShare/Sina、东方财富 | 大部分可解决 | 当前版本财务事实 |
| 总股本/流通股本 | 巨潮 `p_stock2215` + BaoStock | 仍有小缺口和冲突 | 事件主源+回退 |
| 历史修订前版本 | 巨潮原始公告文档 | 工程上可行，未完成 | PIT关键主源 |
| 历史概念成员 | 无可靠免费现成接口 | 不能直接解决 | 从今天开始留档 |
| 本地下载管理 | 现有项目 | 已具备 | 不引入qteasy |
