# Alpha158 多因子 v4 M2 免费基本面来源与原始层审查

## 目标

本阶段只审计来源并归档原始响应，不构造因子、不训练模型、不输出收益。正式结论必须以固定样本真实采集后的审计报告为准。

当前状态：`M2_VERIFIED_RAW_LAYER_ONLY / RESEARCH_ONLY`。

## 来源路由

- CNINFO 公告元数据和原始公告文档：主来源候选，用于公告时间与修订版本；
- 新浪三大报表：辅助交叉校验，存在“同报告期只暴露当前值”的最新重述风险；
- 东方财富报表：辅助交叉校验，包含退市接口，但不能静默替代 CNINFO 公告版本；
- 正式数值事实只能来自可追溯到具体 CNINFO 公告文档的提取结果；辅助来源冲突只登记，不覆盖。

## 原始层约束

- 响应体按 SHA256 内容寻址；
- 相同响应复用 blob，但每次采集保留独立批次元数据；
- 空响应、无公告、源不支持、网络失败、HTTP失败和解析失败分别编码；
- 请求参数、获取时间、HTTP状态、来源版本、币种和单位进入批次元数据；
- token、cookie、Authorization、API key 等字段递归脱敏；
- 审计和采集输出均不得覆盖已有文件。

## 固定样本

样本覆盖沪深主板、创业板、科创板、金融、非金融、历史ST和退市证券。真实来源审计需要执行：

```bash
.venv/bin/python scripts/collect_fundamental_pit_v4.py --download-documents
.venv/bin/python scripts/audit_fundamental_pit_v4.py \
  --output /Users/wjy/abu/data/selection_research/fundamental_source_audit_20261003.json
```

若公告版本、原始文档或退市样本覆盖不合格，审计输出 `BLOCKED_DATA_GATE`，M3—M10必须暂停。
