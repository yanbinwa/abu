# Alpha158 Ridge事件退出标签消融验证

## 结论

状态：`REJECT_HISTORICAL_SCREEN / RETAIN_RESEARCH_CANDIDATE`

将训练目标从固定20日沪深300超额收益排名替换为执行感知的60日事件退出R后，OOS事件标签IC、三档成本累计收益、ES95及连续跌停压力结果均改善。25bp下收益和回撤同时改善，说明事件标签包含有价值的信息。

但20日区块Bootstrap下界仍跨零，40/60bp最大回撤恶化，且候选平均仓位比对照低约1.8—2.0个百分点，未满足冻结的可比性门槛。因此该标签可以保留为下一阶段研究候选，但不能替换正式模型，也不能据此进入复杂模型调参。

## 账户层结果

## 未通过门槛

20项机械门槛中14项通过、6项失败：

1. 20日区块Bootstrap的年化收益增量95%区间为约 `[-0.690pp, +2.079pp]`，下界未大于零；
2. 25bp平均仓位差为1.77pp，超过1pp容忍范围；
3. 40bp最大回撤恶化约0.39pp，平均仓位差1.91pp；
4. 60bp最大回撤恶化约0.94pp，平均仓位差1.77pp。

25bp年度收益在14个自然年度片段中有8个优于对照，2014—2016、2018—2020、2022和2024改善；2013、2017、2021、2023、2025和2026落后，其中2026落后3.33pp。跨年度方向仍不稳定。

## 解释边界与下一步

本实验使用的历史已经被多轮观察，只能作为历史筛选证据。事件标签Ridge继续保持研究候选身份，正式策略和前瞻账户不变。

下一步不应立即调Ridge参数或切换LambdaRank。应先完成两个预注册诊断：

1. 固定持股数的Top10/Top20事件R比较，隔离股票选择与账户仓位差异；
2. 对2017、2021、2023和2026等落后年份按退出原因、行业、持有期及市场状态归因，判断失败是否来自可重复的状态暴露。

只有固定持股数下仍有增益，且弱势年份风险来源可由事前状态变量解释，才值得注册一个固定风险预算的shadow账户。不得根据本轮结果反向挑选年份、阈值或风险倍数。
