# 日线选股与分钟执行系统 v1 — MS4 Review

## 结果

实现不可变执行指令、追加式订单事件、独立 `IntradayTradability`、M1/M2 全成或不成状态机，以及通过共享执行器提交成交/取消的适配函数。

## 因果性保证

- 触发 Bar 固定为结束时间 09:35。
- 最后决策分钟为 10:29，最后候选 Bar 开始时间为 10:30。
- 候选价取首个 `bar_start >= execution_eligible_at` 的一分钟 Bar 开盘价。
- M2 容量只使用此前完成的参考 Bar；候选 Bar 成交量不参与成交决定。
- M1/M2 不引用 SelectionPanel 或 `buy_tradable_mask`。
- 基础涨停模型与悲观敏感性模型分开运行。

## 账户保证

等待容量、价格或候选 Bar 时不释放预留。只有成交、取消或过期通过共享执行器进入终态并释放一次。
