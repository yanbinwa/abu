# Alpha158-lite 低频组合 v3 验证报告

## 结论

低频约束显著改善了 Alpha158-lite 的可交易结果，并将年买入次数压到冻结目标以内。策略从高频版本的明显亏损转为正收益，但收益仍低于沪深300，年度稳定性和极端流动性压力未通过，因此只保留为候选研究版本。

## 当前模型版本

主分支已经将标签修正为包含25bp买入滑点，并按信号日等权训练。修正后的样本外结果为：

- 日均 Rank IC：`+0.1273`；
- 移动区块95%区间：`[+0.0739, +0.1755]`；
- IC 为正日期比例：`72.17%`；
- Top10 的20日超额收益提升：`+0.7398`个百分点；
- 13个滚动测试块、772个样本外信号日、1,981,817个候选。

低频组合使用以上修正版预测，没有复用旧配置缓存。

## 交易约束

- 每5个交易日评估一次排名；
- 连续两次进入前50才允许买入；
- 至少持有10个交易日后才允许排名卖出；
- 连续两次跌出前100才允许排名卖出；
- 每次评估最多因排名替换1只；
- 初始止损、跟踪止损和停滞退出仍逐日执行；
- 不采用固定持有20日。

## 结果

|---|---:|---:|
| 成本后收益 | -18.8833% | **+3.6005%** |
| 最大回撤 | -19.0406% | **-6.9768%** |
| 日 ES95 | -0.8089% | -0.6372% |
| 平均暴露 | 18.7055% | 14.1854% |
| 买入次数 | 2,303 | **357** |
| 年均买入次数 | 约724 | **112.31** |
| 持仓中位数 | 约2日 | **15日** |
| 平均持仓 | — | 17.79日 |
| 90%持仓期限 | — | 35日以内 |
| 平均 R | -0.0903R | **+0.0718R** |
| 总交易摩擦 | 25.9926% | **3.8332%** |

交易次数下降84.50%，固定路径毛收益没有因降低频率而消失，说明“持续性确认 + 排名迟滞”比每日替换更符合20日预测目标。

## 年度结果

| 年份 | 成本后收益 |
|---|---:|
| 2023，自7月27日 | -0.1812% |
| 2024 | +0.4471% |
| 2025 | +4.4535% |
| 2026，截至9月30日 | -1.0789% |

年度表现仍不稳定，正收益主要来自2025年。同期沪深300累计收益为 `+11.6666%`，低频组合只有 `+3.6005%`。

相同的2023年7月27日至2026年9月30日期间，原 VCP 基线收益约为 `-4.5667%`、最大回撤 `-6.4906%`。低频 Alpha158 的收益更高，但最大回撤略大约0.49个百分点。

## 退出与压力

347笔卖出包括：

- 持续排名退出：128；
- 初始止损：129；
- 跟踪止损：60；
- 停滞退出：30。

期末仍持有10只股票。假设全部持仓继续经历3个跌停板，期末收益由 `+3.6005%` 降为 `-4.4082%`，压力路径最大回撤为 `-14.8283%`。因此该版本未通过现有组合压力准入门槛。

## 判断

本实验支持三个结论：

1. 每日排名换仓确实破坏了选股收益，是高频版本亏损的核心原因；
2. 20日横截面分数适合配合持久性确认和迟滞退出，而不是固定20日持有或每日全量换仓；
3. 当前低频版本的绝对收益、年度一致性和极端流动性压力仍不够，不能进入实盘或正式模拟盘。

本版本是在观察 v1/v2 后形成，属于历史诊断。下一步应冻结 v3，从新的未观察行情开始验证，而不是继续在相同历史上调整5日、10日、50名或100名等参数。
