# Alpha158 多因子 v4 M3 PIT事实、TTM与股本审查

## 目标

M3把带原文哈希的显式提取记录转换为可按任意时间截断的事实。任何记录缺少公告、修订、单位、币种或原文证据时失败关闭。

当前状态：`M3_VERIFIED_ENGINE / RESEARCH_ONLY`。

## 实现边界

- `FundamentalFact` 保存报告期、报告类型、公告日、可见时间、修订、来源、单位、币种、映射版本和原文SHA256；
- 只有日期的公告从下一交易日09:25起可见，不能进入公告当日收盘信号；
- `FundamentalFactStore` 对显式 `asof_timestamp` 查询，未来修订不会覆盖过去；
- 利润表和现金流量表按Q1、H1、Q3、FY累计值推导单季，缺少前一期时返回原因而不是填充；
- TTM要求连续四个单季，跨年按季度序号勾稽；
- 资产负债表平均余额要求两个当时已可见的端点；
- `ShareCapitalStore`分别保存总股本和流通股本；
- CNINFO股本表以 `F003N` 表示总股本、`F022N` 表示与A股行情匹配的人民币普通股流通股；不再使用可能包含B/H股的 `F021N` 计算A股流通市值；
- 股本查询同时约束公开可见时间和经济变动日期，避免较晚披露的旧报告期快照回滚较新的股本变动；
- 总市值只能使用原始收盘价×总股本，流通市值只能使用原始收盘价×流通股本；
- 非CNY、未知单位、非有限值、零股本和流通股本大于总股本都会失败关闭。

## 重要限制

标准化入口不从表头或文件名猜测来源。上游必须先把每个数值绑定到具体 CNINFO 公告文档及原文哈希。新浪/东方财富当前值可以用于交叉校验，但不能以主来源身份进入正式事实表。

2026-10-03 路线调整后，允许东方财富结构化快照作为数值主来源候选，但仅在 `max(NOTICE_DATE, UPDATE_DATE)` 之后生效，且必须标记其历史修订覆盖是否完整。PDF与公告版本解析暂停；在结构化试点证明修订历史完整前，M5仍然失败关闭。
