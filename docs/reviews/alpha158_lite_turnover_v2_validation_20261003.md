# Alpha158-lite 换手约束 v2 验证报告

## 结论

`alpha158_lite_turnover_v2` 将排名原因的替换限制为每天最多 1 只，同时保留即时止损、跟踪止损和停滞退出。该修改显著降低换手并改善收益和回撤，但成本后仍亏损，不能进入模拟盘。

该实验是在观察到 v1 高换手后提出，属于历史诊断，不能视为独立样本外证据。

## 原因判断

限制换手后，交易摩擦减少约 13.38 个百分点，证明 v1 的每日排名替换确实是主要亏损来源之一。

但固定路径毛收益同时从 7.13% 降至 1.52%。当前分数虽然能预测 20 日横截面收益排名，其高分股票变化仍很快；强行降低替换速度会继续持有已经失去相对优势的股票。因此，“扩大缓冲或减慢交易”只能在 alpha 衰减与成本之间移动，不能创造足够的净收益。

当前失败不应归因于止损太宽或组合风险预算。下一阶段需要直接预测成本后的持仓增量价值，并在训练目标中加入换手惩罚、分数稳定性和现有持仓继续持有的机会成本。该研究必须建立新版本，不能继续用本轮结果挑选替换上限。

最终决定：保留 v2 的改善证据，但拒绝策略准入，停止在当前历史样本上搜索 Top-k、缓冲区和每日替换数量。
