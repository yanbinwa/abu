# Alpha158 浅层非线性排序验证（2026-10-05）

## 结论

固定规格的浅层 `HistGradientBoostingRegressor` 未通过历史筛选，结论为
`REJECT_HISTORICAL_SCREEN`。当前 Ridge 排序继续保持不变，非线性模型不进入模拟盘，
也不围绕本次结果继续搜索树深、学习率、叶节点或选股阈值。

本次结果说明，平均横截面 Rank IC 的小幅改善没有转化成头部选股和账户收益改善。
模型提高了平均持仓比例，但新增持仓的质量不足，不能将“提高仓位”解释为“提高有效收益”。

## 预登记设计

- 特征：原样使用 `alpha158_lite_features_v1` 的 26 个价格、趋势、波动、流动性和行业特征；
- 标签：原样使用从下一交易日可执行开盘开始的 20 日沪深300超额收益横截面排名；
- 切分：与当前 Ridge 相同的 20 日清除式 expanding walk-forward；
- 模型：单一浅层直方图梯度提升配置，`max_depth=3`、`max_leaf_nodes=7`、
  `min_samples_leaf=500`、`max_iter=60`、`learning_rate=0.05`、`L2=1.0`；
- 组合：目标10只、每5个交易日评审、连续两次入围、取消排名退出，保留初始止损、
  移动止损和停滞退出；
- 成本：25bp 滑点和现有费用、涨跌停、停牌、T+1及风险约束；
- 参数搜索：无；历史区间已经观察过，不是新留出样本。

预登记文件：
`configs/selection/alpha158_ranker_nonlinear_research_v1.json`。

## “每日 PE 数据受阻”的准确解释

门禁并不是因为缺少一个供应商直接给出的逐日 `PE` 字段。逐日 PE 可以自行计算：

```text
PE(t) = 当日 PIT 总市值(t) / 截至 t 已公开且有效的 TTM 归母净利润(t)
E/P(t) = 1 / PE(t)
```

真正受阻的是构成该比率的历史事实是否在当时可见且可复核：

1. 结构化财务接口没有暴露完整的原始公告、更正公告和版本替代关系；
2. 当前没有通过验收的全市场规范化 PIT 财务事实层，因此不能可靠生成历史 TTM 净利润；
3. 总市值覆盖率已达到99.9622%，但股本来源仍有持续性口径冲突；
4. 流通市值覆盖率为98.4265%，低于99.5%门槛；
5. 价值、质量和投资三个主题的可审计覆盖率目前仍为0。

行情接口提供的“历史 PE”如果没有说明每一天使用的公告版本，可能用后来重述的利润回填过去，
造成前视偏差。因此它只能用于交叉核对，不能替代 PIT 财务事实主数据。
