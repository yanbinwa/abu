# VCP 优化实验 v2 验证报告

## 1. 结论

本轮按照预先冻结的规范完成退出规则消融和 `VCP + 残差动量` 混合信号验证。主候选从可执行止损基线的 `-10.69%` 改善到 `+1.44%`，placebo 分位从旧核心策略的 `28.9%` 提升到 `56.6%`。

改善是真实的，但仍未达到策略有效性门槛。主候选保持 `research_only / NOT_ELIGIBLE`，不得进入模拟盘或实盘。

## 2. 风险口径修正

旧 `d_core_r_fixed20` 使用初始止损距离计算 R 仓位，却没有在持有期执行该止损。它可以衡量仓位缩放的效果，但不满足“每个 R 都对应真实可执行止损”的要求，因此不能作为可准入的风险策略。

新实验全部在收盘触发初始止损，下一交易日通过统一成交模型卖出；跌停或停牌时卖单延期。

## 3. 退出规则消融

| 实验 | 成本后收益 | 最大回撤 | 买入笔数 |
|---|---:|---:|---:|
| D：影子止损计算 R、固定20日 | -0.16% | -7.76% | 207 |
| 初始止损 + 最长20日 | -10.69% | -14.25% | 267 |
| 初始止损 + 突破失败 + 最长20日 | -9.01% | -13.88% | 375 |
| 初始止损 + 跟踪止损 + 最长20日 | -9.06% | -12.72% | 279 |
| 初始止损 + 市场退出 + 最长20日 | -8.68% | -12.31% | 268 |
| 初始止损 + 跟踪止损 + 停滞退出 | -1.20% | -11.35% | 173 |

结论：

1. 真正执行初始止损后，旧核心信号频繁止损，证明当前止损距离与信号噪声不匹配。
2. 突破失败和市场状态退出只有有限改善，不能修复负期望。
3. 取消无条件20日退出，让达到1R的盈利仓位继续运行，收益改善最明显。
4. 退出优化能够改善盈亏分布，但无法代替有效的入场信号。

## 4. 混合信号

`vcp_residual_v2` 保留 VCP 全部硬条件，只增加既有残差动量的冻结定义：使用 `t-251...t-21` 估计 beta，使用 `t-125...t-21` 计算残差动量，并要求残差动量为正。排序由残差动量、MA120斜率、收缩紧度和突破强度四项等权组成。

| 实验 | 成本后收益 | 最大回撤 | 买入笔数 |
|---|---:|---:|---:|
| 混合信号 + 初始止损 + 最长20日 | -6.29% | -9.70% | 246 |
| **混合信号 + 初始止损 + 跟踪止损 + 停滞退出** | **+1.44%** | **-8.79%** | **137** |

主候选年度表现：

| 年度 | 收益 |
|---|---:|
| 2022 | 0.00% |
| 2023 | +3.78% |
| 2024 | +0.93% |
| 2025 | -3.44% |
| 2026 截至9月30日 | +0.28% |

主候选平均仓位只有 `8.14%`。直接交易成本为26,155元，其中滑点21,615元。按固定交易路径加回成本后累计收益约 `+4.05%`，仍属于较薄的成本前优势。

## 5. 交易结构

- 已闭合交易：137笔

- 平均亏损：-5.09%
- 成本后 Profit Factor：1.061
- 成本前参考价 Profit Factor：1.257
- 前5笔盈利占全部正收益：48.94%

退出归因：

| 原因 | 笔数 | 胜率 | 合计盈亏 |
|---|---:|---:|---:|
| 初始止损 | 71 | 0% | -140,175元 |

策略依靠少数能够进入跟踪止损阶段的趋势交易覆盖大量初始止损，收益集中度仍然偏高。

## 6. 匹配型 placebo

1,000组 placebo 与主候选使用相同的风险审批、初始止损、跟踪止损、停滞退出、现金约束和成交模型。

| 指标 | 结果 |
|---|---:|
| 主候选收益 | +1.44% |
| Placebo 平均收益 | +0.85% |
| Placebo 中位收益 | +0.55% |
| Placebo 5% / 95%分位 | -6.40% / +9.53% |
| 主候选分位 | 56.6% |
| 主候选最大回撤 | -8.79% |
| Placebo 最大回撤中位数 | -8.23% |

有434组随机组合收益高于主候选。混合信号略高于随机中位数，但没有进入前10%，不能证明横截面选股 alpha。

## 7. 统计和压力测试

- 入场日期簇：87个
- 平均交易结果：+0.283R
- 95%交易簇 bootstrap 区间：`[-0.313R, +0.984R]`
- FDR q值：`0.203`
- 三跌停压力清算最大回撤：`-15.45%`

每种5,000条时间区块路径：

- 终值亏损概率：41.4%–43.4%
- 终值收益5%分位：-9.45%–-10.27%
- 95% Expected Shortfall：-11.88%–-13.12%
- 最大回撤中位数：-6.83%–-7.27%
- 最大回撤5%分位：-13.20%–-14.28%

交易簇置信区间仍跨过零，统计显著性和 placebo 门槛均失败。

## 8. 最终决定

主候选仅通过以下门槛：

- 成本后累计收益为正；
- 已闭合交易超过100笔；
- 压力清算回撤低于20%；
- 无未退出持仓和账本异常。

未通过：

- placebo 前10%；
- 交易簇置信区间下界为正；
- FDR；
- 跨年度稳定盈利。

本版本应冻结为一次失败但有诊断价值的研究记录。下一步不应继续使用同一时期搜索权重、窗口或止损倍数；需要新的时间样本、前瞻模拟，或更换能够独立提出经济假设的信号家族。
