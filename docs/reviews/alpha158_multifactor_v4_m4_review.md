# Alpha158 多因子 v4 M4 股票池与覆盖门禁审查

## 目标

M4验证全市场数据是否足以进入单因子研究。工程能力通过和真实数据门禁通过是两个独立结论。

当前状态：`M4_BLOCKED_DATA_GATE / RESEARCH_ONLY`。

## 实现

- 日期分区 sidecar 每次只读取一个截面，避免把稀疏基本面复制成价格同尺寸矩阵；
- 三套股票池固定为全合格、排除总市值最小30%、总市值前50%；
- 30%使用向下取整，50%使用向上取整，并用证券代码解决市值并列；
- 大中盘集合必须是主集合子集，主集合必须是全合格集合子集；
- 基础资格、主题缺失、总市值缺失和市值分位排除均有原因码；
- 覆盖报告按日、交易所、行业、来源、主题、ST、总/流通市值和修订分别统计；
- 低覆盖保留为缺失，不能通过横截面中位数填充变成通过。

## 股本重放与市值物化复核（2026-10-03）

后续勾稽发现初版将 CNINFO `F021N`“已流通股份”用于A股流通市值，该字段可能包含B股和H股；同时，股本接口混有真实变动与定期报告快照，只按公告可见时间取最后一条会被较晚披露但经济日期更早的快照回滚。现已修正为：

- A股流通股本使用 `F022N`“人民币普通股”；
- 先按公开时间过滤，再按经济变动日期选择最新状态；
- 从不可变原始响应重放50个已选批次，逐个验证payload哈希，不重新联网、不覆盖初版结果；
- 总股本缺失时允许资产负债表 `SHARE_CAPITAL` 补全总股本；日线 `outstanding_share` 只能补全缺失的流通股本，不能把总股本推断成流通股本；
- 主辅来源超过0.5%冻结容差时保留主值并显式记录冲突，不静默择优。
