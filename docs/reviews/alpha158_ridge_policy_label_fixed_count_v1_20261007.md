# Alpha158事件标签Ridge固定持股数与弱势年度诊断

## 结论

状态：`COMPLETE_DIAGNOSTIC_ONLY / NEGATIVE_FIXED_COUNT_EVIDENCE`

固定每日选股数量后，事件标签Ridge的Top10、Top20和Top11—20平均事件R全部低于原标签Ridge。Top10和Top20的20日区块Bootstrap区间完全低于零。因此，上一轮账户收益改善不能归因于“相同持股数量下选出了更高平均R的股票”，更可能来自更高胜率、较低换手、较长持有期、较低平均仓位及账户风险路径共同作用。

## 固定持股数结果

选择严格先于结果评价发生。每天先按当时OOS分数选择Top10或Top20，再检查事件标签；缺失未来标签的入选股票不会由下一名补位。

20日区块Bootstrap日均R增量95%区间：

- Top10：`[-0.2370R, -0.0110R]`；
- Top20：`[-0.2058R, -0.0189R]`；
- Top11—20：`[-0.2048R, +0.0027R]`。

事件标签模型的胜率高约2个百分点，但平均R更低。这解释了“全截面事件IC显著提高、账户总收益提高、固定数量平均R却下降”的表面矛盾：当前监督目标是事件R的横截面百分位排名，极端大赢家被压缩到接近 `+0.5`，Ridge日期等权MSE更重视全截面次序和高频小胜负，而不是Top10中的收益幅度。

## 年度差异

固定Top10下，事件标签模型仅在2013、2016、2019、2023、2024和2026提高平均R；在2014、2015、2017、2018、2020—2022和2025下降。账户年度增量与固定数量年度增量也并非一一对应，进一步证明成交时序、连续入围、退出和风险预算产生了显著路径影响。

## 弱势年度归因

25bp账户增量为负的年度片段为2013、2017、2021、2023、2025和2026。2013只是短起始片段，主要解释集中在其余年度。

候选在这些年度的已实现交易合计：

- 初始止损：`-144,891`元；
- 停滞退出：`-34,976`元；
- 跟踪止损：`+187,053`元。

主要模式如下：

1. 2017年：上涨低波动状态下候选已实现亏损约3.03万元，对照约1.29万元；机械设备行业贡献约 `-2.31`万元。
2. 2021年：候选21—60日持仓亏损约0.73万元，而对照盈利约1.33万元；候选跟踪止损盈利也明显较少。
3. 2023年：候选跟踪止损盈利约3.12万元，对照约6.24万元；对照在计算机行业获得约3.42万元盈利，候选没有捕获同等尾部收益。
4. 2025年：两者已实现交易盈亏接近，账户差异更多来自年末持仓和逐日盯市路径，不宜用退出交易单独解释。
5. 2026年：候选跟踪止损盈利约3.47万元，对照约6.08万元；候选在下跌高波动状态出现约1.24万元日度亏损，而对照同期为正。

弱势年度合并看，候选相对对照最大的行业拖累来自机械设备、计算机、房地产、建筑装饰和电力设备；但该归因是事后解释，不能直接转化为行业过滤规则。

## 研究含义

事件百分位标签更像一个“提高胜率、减少交易”的质量信号，不是更好的头部收益幅度排序器。下一步若继续研究，应把它定位为独立shadow确认信号，而不是替换原20日Ridge：

1. 原20日模型继续负责候选排序；
2. 事件模型只记录确认分数、预期胜率和拒绝原因，不立即改变订单；
3. 在新的前瞻数据上检验事件分数是否能识别初始止损和低质量停滞交易；
4. 不根据本轮历史事后选择行业、市场状态阈值或混合权重。

如果未来重新设计监督目标，应单独注册保留收益幅度的稳健变换，例如预先冻结的截尾R或有符号对数R；不能把该改动与LambdaRank、行业过滤或仓位调整同时进行。
