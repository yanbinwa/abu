# 日线选股与分钟执行系统 v1 — MS3 Review

## 结果

执行器新增交易日开始、开盘卖出、待执行买单、外部买入成交、取消和 D0 买入接口。原 `process_open()` 仍是 D0 兼容入口，并继续使用遗留 `buy_tradable_mask`。

## D0 边界

- 本阶段没有修正 D0 对当日收盘和全天成交量的依赖。
- M1/M2 不调用 `_fill_buy()`，后续由独立 `IntradayTradability` 决策。
- 外部成交仍通过同一个费用、现金、持仓和 PositionLedger 路径记账。

## 状态隔离

新增 Fill 字段均有兼容默认值。共享执行器文件哈希已变化，因此现有纸上实例仍会按原机制拒绝加载；不得更新或覆盖其状态。分钟影子运行必须使用独立状态目录。
