# M8 只读控制台阶段验收

日期：2026-10-05

## 结论

M8-T01、M8-T02 软件实现通过，结论为 `READ_ONLY_DASHBOARD_ACCEPTED`。这不是完整 M8 准入。

## 范围

- `DashboardQuery` 使用 SQLite URI `mode=ro` 并启用 `PRAGMA query_only=ON`；
- 展示服务实例、作业、审计项、事件水位线和 snapshot；
- 展示多账户余额、日结权益以及单账户持仓、lot、逻辑交易、订单、成交、风险审批、
  日结、对账、通知和账户事件；
- 生成静态首页和账户详情页，不提供 HTTP 写接口；
- 账户页文件名使用账户 ID 的 SHA-256 摘要，账户 ID 不能造成路径越界；
- 页面输出使用 HTML 转义，静态文件采用同目录临时文件、`fsync` 和原子 rename；
- `dashboard.build` 已加入项目调度目录，只有显式 `--enable-dashboard` 才注册 handler。

## 自测

定向测试覆盖：

- query-only 连接拒绝 `UPDATE accounts`；
- Mock 成交可以追溯到持仓、成交、风险决策、对账和通知；
- 删除页面后可从数据库重新构建；
- 未知账户失败关闭；
- 特殊账户 ID 不能越过输出目录；
- Mock 场景和账户投影未发生回归。

定向结果：8 项通过。
