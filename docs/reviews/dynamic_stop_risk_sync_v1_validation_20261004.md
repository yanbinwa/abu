# 动态止损与组合风险同步 v1 验证报告

## 结论

动态止损同步修复了组合风险长期占用初始止损的问题，并在不提高任何风险上限的情况下提高了仓位。它对 Alpha158 产生正向收益增量，但对 VCP 完整历史产生负向收益增量；两个版本的三跌停压力结果仍未通过，因此不能据此提高风险比例或进入实盘。

拒单原因修正后，旧日志中的大量 `STRESS_LOSS` 被确认是上游开放风险已经把数量降为零后的连带标签。当前真正主要的约束是组合开放风险和同日新增风险。

## 冻结输入

- 风险配置仍为 `risk_v1`，所有比例不变；
- VCP基础意图共 `3,158` 条，开关前后逐行一致；
- Alpha158使用同一个修正版OOS预测文件，SHA256为 `190375561aa37082ea5cde7358145c63a30a7f35d179dc0d0f4927317b378bf0`；
- 成交费用和单边25bp滑点不变；
- 结果均为历史诊断，不是新的独立样本。

## 基线复现

关闭动态同步后：

- VCP收益 `+1.4363%`、最大回撤 `-8.7863%`，与冻结结果一致；
- Alpha158收益 `+3.6005%`、最大回撤 `-6.9768%`，与冻结结果一致。

这说明新增持仓字段和拒单原因修正没有改变旧经济路径。

## 年度稳定性

VCP动态同步后的年度收益为：2023年 `+1.76%`、2024年 `+0.83%`、2025年 `-4.04%`、2026年截至9月30日 `-0.67%`。它比基线在多数有效年度更差。

Alpha158动态同步后的年度收益为：2023年部分期间 `-0.69%`、2024年 `+0.34%`、2025年 `+3.52%`、2026年截至9月30日 `+1.35%`。收益仍不稳定，但2026年改善明显。

## 拒单归因

修正后的基线不再出现伪 `STRESS_LOSS`：

- VCP基线主要为组合开放风险392次、行业风险43次、同日风险13次；
- Alpha158基线主要为组合开放风险1,109次、同日风险435次、行业风险92次；
- 动态同步后VCP组合开放风险降至71次；
- 动态同步后Alpha158组合开放风险降至212次，但同日新增风险仍有438次。

原因次数允许重叠。动态同步只释放已经被实际止损保护的开放风险，没有提高风险比例。

## 决策

1. 保留动态止损同步能力，旧冻结结果通过显式开关继续可复现；
2. VCP不采用动态同步版本作为收益候选，继续保留原基线；
3. Alpha158动态同步版本保留为研究候选，但由于三跌停清算收益和压力回撤恶化，仍为 `research_only`；
4. 不提高0.25%单笔风险、2%组合风险或其他风险上限；
5. 若继续提高资本利用率，应单独预登记“受保护盈利仓位加仓”或“低风险现金替代资产”实验，不能通过直接放宽风险预算实现。
