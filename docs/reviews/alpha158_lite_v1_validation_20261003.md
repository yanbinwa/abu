# Alpha158-lite v1 验证报告

## 1. 结论

`alpha158_lite_v1` 通过因子预测门槛，但没有通过可交易组合门槛，最终状态为：

```text
RESEARCH_ONLY / REJECT_AT_PORTFOLIO_STAGE
```

不得继续运行 LightGBM、参数搜索、placebo 或实盘准入。该版本证明宽股票池横截面数据含有可预测信息，但当前每日排名换仓无法在交易成本后保留该优势。

## 2. 冻结口径修正

本轮在揭示真实结果前完成以下修正：

- 标签排除次日停牌、开盘涨停、跳空超过1ATR以及25bp滑点后超过涨停价或最高买价的样本；
- 标签成交判定与 `pit_corrected` 执行器保持一致；
- Ridge按信号日等总权重训练，避免股票池扩张使后期日期获得更大权重；
- 保存1、5、10、20、60日因子衰减诊断；
- 加入20日移动区块Bootstrap Rank IC区间；
- 组合报告增加三跌停清算净值、期末持仓和未完成订单。

参数未根据本轮结果修改。

## 5. 成本与持有期归因

Ridge组合：

- 总直接费用与滑点约259,944元，其中滑点约211,005元；
- 2,175笔退出来自 `RANK_EXIT`，远高于119笔初始止损；
- 持有期中位数仅3个自然日，平均4.44个自然日；
- 参考开盘价口径平均单笔收益为 +0.263%，正收益比例52.35%；
- 完整成交和费用后平均单笔收益为 -0.502%，正收益比例41.43%。

模型训练目标是20日超额收益，但每日重新排名使大多数仓位约3日退出。预测信号存在，然而决策周期与标签周期不一致，且单笔毛优势不足以覆盖高换手成本。

## 6. 停止决定

按照预登记顺序：

1. Ridge因子层通过；
2. Ridge统一执行组合失败；
3. 因此不运行LightGBM挑战模型；
4. 因成本后收益为负，不运行placebo和正式准入压力流程；
5. 不修改Top10/Top20、止损倍数或Ridge参数来挽救该历史结果。

## 7. 后续独立假设

如建立v2，应先冻结“标签周期与交易周期一致”的单一方案，例如按周建立固定批次、最多持有20个交易日，并限制同期批次数量。该方案来源于本轮机制诊断，只能作为新的历史开发实验；其结果不能恢复v1的准入资格。真正有效性仍需新的前瞻样本。
